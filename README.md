# InterviewJS

A frontend-only interview practice application built with HTML, CSS and vanilla JavaScript.

## Files
- index.html — structure and routes/screens
- style.css — responsive UI, light/dark theme
- app.js — question bank, state, shuffle, timer, scoring, history, validation and routing

## Run
Open `index.html` directly in a modern browser.

## Important
The contact form currently uses a placeholder `hello@example.com` and opens a mail client. Replace it with the real address or connect the form to a backend/form service before deployment.

No external font/CDN is required.
